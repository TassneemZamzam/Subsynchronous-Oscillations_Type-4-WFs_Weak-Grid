# WG-PMSG-SSO Benchmark System and EMT Dataset
This repository contains the materials associated with the paper entitled **"A Network-Side Assessment Framework and Benchmark System for Weak-Grid PMSG-Based Sub-Synchronous Oscillations"**.

The repository contains:
- WG_PMSG_SSO_Benchmark.pscx: The PSCAD implementation of the modified IEEE 39-bus benchmark system with an integrated permanent magnet synchronous generator (PMSG)-based wind farm (WF).
- WG_PMSG_SSO_WF2.csv: The generated electromagnetic transient (EMT) simulation dataset used in the study, including the identified weak-grid PMSG-based sub-synchronous oscillation (WG-PMSG-SSO) scenarios.
  - The corresponding oscillation characteristics, including sub-synchronous oscillation frequencies and magnitude ratios, together with the associated operating and disturbance conditions, such as short-circuit ratio (SCR), fault type, and fault location.

These resources are provided to support the reproducibility of the results presented in the paper and to facilitate future research on weak-grid stability assessment and WG-PMSG-SSO analysis.

**Cite**: T. Zamzam, Y. Qiblawey, A. Alassi, H. Abu-Rub, A. Massoud and A. Ghrayeb, "A Network-Side Assessment Framework and Benchmark System for Weak-Grid PMSG-Based Subsynchronous Oscillations," in IEEE Open Journal of the Industrial Electronics Society, vol. 7, pp. 1401-1420, 2026, doi: 10.1109/OJIES.2026.3724912.
